Unbar carries your internet traffic inside DNS queries, through a server of your own, so you stay connected when direct internet access is cut but DNS still answers. It is built on the Soar tunnel, by Break The Barriers.

Unbar ships with no built-in server. You add your own server (zone + Ed25519 public key), or import a config from someone who runs one.

Features:

* VPN mode for all traffic, or SOCKS proxy mode for selected apps
* Resolver scan: DNS and RTT screening, a Soar handshake, then ranking into one pool; dead resolvers are replaced automatically
* Scan over UDP or UDP + TCP (also keeps resolvers that answer only over TCP); remembered resolvers are tagged UDP, TCP or UDP·TCP; Pause, Resume and Stop
* Healthy resolvers remembered per network (mobile carrier or Wi-Fi), with a global fallback; no location permission, the Wi-Fi name is never stored
* Built-in Iranian resolver list, your own resolvers (CIDR ranges supported), or import a .txt list: it is cleaned, scanned and only verified resolvers are kept. Before a scan, Custom and Import lists show how many resolvers they give and warn when a range wider than /20 is skipped or the list is capped at 5000
* Import and share configs with unbar:// links, JSON or QR codes
* HTTPS subscriptions that keep your server list up to date
* Latency test and auto-select of the fastest server
* Iran geo bypass (.ir and Iranian IPs go direct), custom bypass list and per-app routing
* TCP Mode: adds a TCP/53 path for every resolver next to UDP. Helps when UDP is blocked, but uses more battery. When off, TCP is used only where UDP fails
* Bandwidth limits, auto MTU, and DNS answer size (Auto, 512, 752 or 992; applies on the next connect)
* Shared DNS cache for VPN and SOCKS mode: if the tunnel drops for a moment, names resolved in the last day still answer
* Path diagnostics: live state of every resolver path, with Copy
* Live stats, connection history, Quick Settings tile and home-screen widget
* About screen with the app and Soar core versions, license, links to the website, Telegram channel and source code
* English and Persian, soft "Cloud" light and dark themes

Free software under the GPL-3.0 license.

Privacy: no account, no analytics, no ads, no crash reporting. Diagnostic logs are off by default and stay on your phone.
