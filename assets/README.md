# Unbar — Brand Assets (1.0.2)

Current brand kit, matching the app since version 1.0.2 (S1 wordmark, "Ub" icon, Cloud palette).

## Colours
- Blue ("Un", light): `#1A5BAA` · Blue (dark theme): `#6E9FDB`
- Orange ("bar"): `#F7853A` · Orange (dark theme): `#F7954A`
- Background light `#F2F6FB` · dark `#101722`

## Files — `brand/`
- `logo-tagline-{light,dark}.png` — wordmark with "by Break The Barriers" (README header: `../unbar-logo-{light,dark}.png`)
- `wordmark-{light,dark,black,white}-{512,1024,2048}.png` — wordmark only
- `lockup-{light,dark}-{512,1024,2048}.png` — icon + wordmark
- `icon-{16…1024}.png`, `icon-dark-*.png`, `icon-round-*.png` — app icon ("Ub")
- `icon-fullbleed-1024.png`, `icon-mono-1024.png`, `adaptive-foreground-432.png` — store / adaptive / monochrome
- `favicon.ico`

The Android app uses vector drawables (`unbar_logo_*`, `unbar_wordmark_*`, adaptive icon) and iOS uses `Assets.xcassets`; these PNGs are for web, stores and press.
